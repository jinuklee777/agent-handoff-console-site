03API credits

API credits. Now it’s just a switch.

Max and Team plans include monthly API credits.
But they only apply when Claude Code runs through claude -p or the Agent SDK.⁠2
That’s a hassle from the terminal.
Here, add the key once and flip a switch in the conversation.
Hit your limit? One press of ‘Continue on API credits’ keeps the same session going.

From the terminal

  1. Set the key as an environment variable
  2. Run claude -p on its own
  3. And make sure the key in your shell doesn’t get used by other runs

Here

  1. Paste the key into Settings once
  2. Flip the switch in the conversation you want
  3. Other conversations and your terminal stay on your plan

Create the key in the Claude Console org you connect under claude.ai › Settings › Billing. Paste the wrong kind of key and it tells you right away.

  • Launches the official, unmodified claude
  • Your sign-in never leaves the CLI

Get started.

  1. 1

    Download

    Get the zip from Releases, unzip it and move the app to Applications.

    Download the latest release
    Verify the download (optional)

    Compare its SHA-256 with the release page:

    $ shasum -a 256 ~/Downloads/AgentHandoffConsole-*.zip
  2. 2

    Open it the first time

    v0.1 isn’t notarized yet, so the first time, click Open Anyway in System Settings › Privacy & Security.

    Or use Terminal 
    $ xattr -dr com.apple.quarantine /Applications/AgentHandoffConsole.app
  3. 3

    Open a folder and talk

    Open a folder with ⌘O, then ⌘N for a new conversation. To hand off, click the agent name (Claude · Codex) in the message box, or press ⇧⌘H.

  • macOS 15 or later (tested on macOS 26, Apple silicon). Mac only for now; no Windows or Linux yet.
  • At least one of Claude Code or Codex, signed in, plus one more to hand off to (another agent or account). Don’t have them yet? The app’s first-run check shows how to install them.
  • Git (Xcode Command Line Tools), for the Changes tab, per-conversation worktrees and the Git state in handoffs.
  • Antigravity can’t ask for approval inside the app, so it’s off by default and allowed per project.
Build from source (Xcode 26) 
$ git clone https://github.com/jinuklee777/agent-handoff-console.git
$ cd agent-handoff-console
$ xcodebuild -project AgentHandoffConsole.xcodeproj -scheme AgentHandoffConsole -configuration Release -derivedDataPath build/DerivedData.noindex build

Questions

Can I use it if I’m new to the terminal?

Yes. You only use the terminal to install and sign in to Claude Code or Codex the first time. The app’s start check shows what’s needed and gives you the official guide and the command to paste. After that, chatting, approvals, reviewing changes, committing and handoffs all happen in the app.

Is it free?

Yes. It’s MIT-licensed. The agents’ usage counts against your own Claude, ChatGPT or Google plans — or your API credits, in conversations where you turn them on.

Does it give me more usage?

No. It doesn’t bypass any limit. It lets you keep going with what you already have — another agent or account, or the API credits that come with Max and Team plans — without re-explaining the task.

Is this OK with Anthropic’s terms?

It launches the official Claude Code CLI, unmodified, with your own sign-in — it never handles your tokens or imitates Claude Code. Runs it starts count against your plan’s usage under Anthropic’s current policy, which may change.

Does my code leave my Mac?

Only through the CLIs you already use, under their own policies. That includes a short summary used to title each conversation, which you can turn off in Settings. The app itself has no server and makes no network requests.

Do I need an API key?

No. It uses the CLIs signed in with your subscriptions. On Max or Team, adding a Console API key also lets you spend your monthly API credits — per conversation, with one switch.

Why is the interface in Korean?

v0.1 ships with a Korean UI; English UI is planned for v0.2. The README and this site are in English, and the app screens on this site are shown in English using the planned v0.2 wording.

Notes

  1. [1]Automatic handoff is off by default. Turn it on in Settings › Handoff and pick a 5, 10 or 30 second countdown. It checks the next agent’s CLI, login and usage first; if anything fails, it opens a review card instead of counting down. You can cancel any time before it sends.
  2. [2]Max and Team monthly API credits (Max 5x $100 a month, Max 20x $200, Team per seat) land in the Claude Console org you connect on claude.ai each billing cycle and don’t roll over. They apply when claude -p or the Agent SDK runs with an API key from that org. Amounts and scope per Anthropic’s documentation as of October 2026, and may change. Claude Code only.
  3. [3]Agent requests go out only through the CLIs you already use, under their own policies. The short summary used to title each conversation also goes through the same CLI, and you can turn it off in Settings.
